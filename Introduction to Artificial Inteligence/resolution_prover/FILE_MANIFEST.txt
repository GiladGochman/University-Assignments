CORE PROGRAM CODE
======================================================================

resolution_prover/__init__.py
  - Package initialization file
  - Exports: term, parser, unify, resolution modules

resolution_prover/term.py (200+ lines)
  - Class: Term (base)
  - Class: Variable(Term) - logic variables
  - Class: Constant(Term) - constants like 'alice', 'loc1'
  - Class: Function(Term) - function terms like 'f(X,Y)', 'result(s)'
  - Class: Literal - predicate with arguments, positive/negative
  - Class: Clause - disjunction of literals
  - Methods: substitute(), __repr__(), __eq__(), __hash__()

resolution_prover/parser.py (150+ lines)
  - Function: parse_term() - parses individual terms
  - Function: parse_literal() - parses predicates with ~ prefix
  - Function: parse_clause() - parses full CNF clause with |
  - Function: load_cnf() - reads .cnf file and builds clause set
  - Regex-based parsing: ~Pred(args) | ~Pred2(args) | ...

resolution_prover/unify.py (100+ lines)
  - Function: unify(x, y, subs) - Robinson's algorithm
  - Function: unify_var(var, term, subs) - variable case
  - Function: occurs_check(var, term, subs) - prevents infinite structures
  - Returns: MGU (most general unifier) or None
  - Handles: variables, constants, functions, recursive unification

resolution_prover/resolution.py (100+ lines)
  - Function: resolve(ci, li_index, cj, lj_index) - binary resolution
  - Function: unify_pair(lit_a, lit_b) - unifies complementary literals
  - Detects: tautologies (p and ~p in same clause)
  - Removes: duplicate literals from resolvent
  - Returns: new Clause or None

run_prover.py (150+ lines)
  - Function: interactive_loop(clauses) - main REPL
  - Commands:
    * r i li j lj - resolve clause i literal li with j literal lj
    * a - add new clause (read from stdin)
    * q - quit
  - Function: main() - entry point, loads CNF file

run_proof_script.py (150+ lines)
  - Function: run_proof_script(cnf_path, script_path)
  - Loads CNF and executes pre-defined resolution steps
  - Outputs: formatted proof trace to stdout
  - Reports: step number, clauses, unification, result
  - Detects: empty clause → proof success
  - Function: main() - CLI entry point
