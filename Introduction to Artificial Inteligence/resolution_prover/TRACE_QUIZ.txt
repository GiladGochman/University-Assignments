EXAMPLE 3: Quiz Scenario - Simplified Rescue Problem
Domain: 3-Vertex Evacuation
File: examples/quiz.cnf

======== PROBLEM SETUP ========

Graph:
  Vertices: 1, 2, 3
  Edges:
    - 1-2: FLOODED
    - 1-3: Not flooded
    - 2-3: Not flooded

Initial State:
  Agent location: vertex 1
  People needing rescue: 
    - Vertex 2 (1 person)
    - Vertex 3 (1 person)
  Amphibian kit: vertex 1 (unequipped)

Constraints:
  - To reach vertex 2 directly from 1, must use flooded edge (requires kit)
  - Can reach vertex 3 from 1 directly without kit
  - Alternative: go 1-3-2 without needing kit, or 1-equip-2-3

Goal: PROVE all people rescued
Negated: HasPeople(loc_unsaved, final_s)

======== OPTIMAL SOLUTION ========

Proof Strategy (Path 1-3-2):
1. Traverse 1-3 (not flooded, no kit needed)
   - At(agent, 3, s1) with people rescued at loc3
   - ~HasPeople(loc3, s1)

2. Traverse 3-2 (not flooded)
   - At(agent, 2, s2) with people rescued at loc2
   - ~HasPeople(loc2, s2)

3. Negated goal HasPeople(loc_unsaved) contradicts
   - ~HasPeople(loc2, s2) AND ~HasPeople(loc3, s2)
   - No location has people left
   - Goal PROVED

Alternative Strategy (with kit, path 1-2-3):
1. Equip kit at vertex 1
   - Equipped(agent, s1)

2. Traverse 1-2 (now flooded edge is traversable)
   - At(agent, 2, s2)
   - ~HasPeople(loc2, s2)

3. Traverse 2-3 (not flooded)
   - At(agent, 3, s3)
   - ~HasPeople(loc3, s3)

4. All people rescued (same conclusion)

======== RESOLUTION PROOF ========

CNF Representation includes:
- Initial facts: At(agent, loc1), HasPeople(loc2), HasPeople(loc3), HasKit(loc1)
- Flooded edge: Flooded(loc1, loc2)
- Non-flooded edges: CanTraverse(loc1, loc3), CanTraverse(loc2, loc3)
- Traversal rules: preconditions for each edge
- Rescue effects: HasPeople removed when agent arrives
- Negated goal: HasPeople(loc_unsaved, final_s)

Resolution Steps (Path 1-3-2 = 5-7 steps):
1. Agent at 1, can traverse to 3 (no kit needed)
2. Derive: At(agent, 3)
3. Derive: ~HasPeople(loc3) from rescue effect
4. Agent moves 3 to 2
5. Derive: At(agent, 2)
6. Derive: ~HasPeople(loc2) from rescue effect
7. Contradiction: HasPeople(loc_unsaved) contradicts ~HasPeople(loc2, loc3)
8. Empty clause derived -> Goal PROVED

======== KEY INSIGHTS ========

1. Multiple solution paths exist (with/without kit)
2. Shorter path is 1-3-2 (avoids needing kit)
3. Resolution proves existence of evacuation plan
4. Demonstrates causal reasoning in situation calculus
5. Proof is complete: derives empty clause (contradiction)
